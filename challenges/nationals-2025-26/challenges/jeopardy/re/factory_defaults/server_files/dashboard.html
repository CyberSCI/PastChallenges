IPBX-AMI — Quick Install Guide
// v1.0.0 · Revision 3 · Initial Deployment Reference
System Requirements
ARCHITECTUREx86_64
CPU2+ cores recommended
RAM512 MB minimum / 1 GB recommended
OSLinux 5.x+ (Debian 11 / Ubuntu 22.04 tested)
PORTS5038/TCP (AMI) · 5060/UDP (SIP) · 5061/TCP (TLS-SIP)
IPCPOSIX shared memory /ipbx_ami (auto-created on first run)
Step 1 — Install Binaries
# copy pre-compiled binaries to system paths
$ sudo cp server /usr/local/sbin/ipbx-server
$ sudo cp consumer /usr/local/sbin/ipbx-consumer
$ sudo chmod 750 /usr/local/sbin/ipbx-server \
/usr/local/sbin/ipbx-consumer
Step 2 — Configure systemd Services
# /etc/systemd/system/ipbx-server.service
[Unit]
Description=IPBX AMI Server
After=network.target

[Service]
ExecStart=/usr/local/sbin/ipbx-server
Restart=on-failure
RestartSec=3

[Install]
WantedBy=multi-user.target
# /etc/systemd/system/ipbx-consumer.service
[Unit]
Description=IPBX AMI Consumer
After=ipbx-server.service

[Service]
ExecStart=/usr/local/sbin/ipbx-consumer
Restart=on-failure
RestartSec=3

[Install]
WantedBy=multi-user.target
$ sudo systemctl daemon-reload
$ sudo systemctl enable --now ipbx-server ipbx-consumer
$ sudo systemctl status ipbx-server ipbx-consumer
Step 3 — Initial Login
The AMI management interface listens on port 5038/TCP. Connect with any TCP client — the server sends a banner (IPBX-AMI/1.0) upon connection.
Authentication requires an AUTH packet whose value field contains base64(user:pass). The server responds with CONT_ACK on success or CONT_ERROR on failure.
DEFAULT USER admin
DEFAULT PASS s3cr3t_pbx
These are factory defaults shared across all IPBX-1000 units. Change the password before connecting the system to any network.
Step 4 — Verify Installation
After both services are running, send a STATUS / SYS_INFO packet (mtype=0x04, ptype=0x30). A well-formed response confirms the server and consumer are communicating correctly.
# expected SYS_INFO response fields
version=1.0.0
uptime=<seconds since boot>
active_calls=<n>
registered_peers=<n>
serial=IPBX-1000
Step 5 — Extension Configuration
Extensions register over SIP on port 5060. The default dial plan is flat — all extensions can reach one another directly. Use STATUS / EXT_STATUS (ptype=0x32, value=extension number) and STATUS / CHAN_LIST (ptype=0x31) to inspect live state via the AMI.
SIP REGISTRARpbx-01.local:5060
AUTH METHODSIP Digest (per-extension credentials in sip.conf)
CODEC ORDERG.722 > G.711u > G.711a
VOICEMAILenabled — query per extension via ptype=0x33
Factory default credentials are identical on every IPBX-1000 shipped from the factory.
Deploying without changing them exposes full AMI control to anyone with network access.
