# RUST IN PEACE - Post-Apocalyptic Disk Manager

## Connection

```
telnet <host> 7000
```

## Background

After the Great Collapse of 2087, civilization's digital infrastructure was reduced to ash. The electromagnetic storms that followed wiped every modern storage device clean. Only the oldest technology survived -- legacy DOS systems running on hardened military hardware, their data preserved on ancient floppy disks and IDE drives.

You are a scavenger who has discovered an abandoned Vault Overseer terminal deep in the wasteland. The system is still operational, running a disk management utility called **PEACE.EXE** on a FreeDOS machine. The terminal provides access to several disk drives containing remnants of the old world's data archives.

But this system holds more than old files. The Vault's security layers protect classified data that could change the balance of power in the wasteland. Breaking through will require understanding how the system was built, exploiting its weaknesses, and thinking like the engineers who designed it decades ago.

## Challenges

This challenge contains **three sequential flags**. Each builds on the previous -- you must solve them in order.

**Part 1: Vault Access**
Can you break into the Vault?

**Part 2: Classified Archives**
You're in but what is the Vault is really hiding?

**Part 3: Core Memory Recovery**
The Wasteland Command Console is yours. Can you coax out its last secrets?
