# Dropped stack

**Author:** 0xd13a

**Category:** Forensics

## Description

Challenge consists of a large number of images of punched cards. The goal is to decode all of them, put them in correct order and discover the message hidden inside.

### Files

`dropped-stack.tar.gz`

### Walkthrough

<details>
<summary>(expand to read)</summary><br>

Provided tarball contains a large number of punched card images, so decoding them manually is not practical, it is better to write a script (see provided [solve.py](solve_files/solve.py) for an example).

Each decoded image has a special composition - a string of 76 characters, a space and then a 3-digit number. Because the images are in random order one can guess that the number is the ordinal card number. The string is consistent with Base32 encoding.

Once decoding is automated and cards are processed in correct order, a binary file is revealed.

The file can be identified as an image in old [PCX format](https://en.wikipedia.org/wiki/PCX):

```
$ file file.bin
file.bin: PCX ver. 3.0 image data bounding box [0, 0] - [492, 11], 3 planes each of 8-bit colour, 300 x 300 dpi, RLE compressed
```
Image can be opened in a powerful graphics editor like Gimp. The flag is written in the image.

</details>
